# Calculadora de IMC em Java

Este é um projeto simples em Java que calcula o Índice de Massa Corporal (IMC) de uma pessoa a partir do peso e da altura informados pelo usuário.

## 📌 Objetivo

Praticar os fundamentos de Programação Orientada a Objetos (POO) em Java com um exemplo prático e fácil de entender.

## 💻 Tecnologias utilizadas

- Java
- Scanner (entrada de dados via terminal)
- Programação Orientada a Objetos

## 🚀 Como funciona

1. O programa solicita ao usuário:
   - Peso (em kg)
   - Altura (em metros)

2. Com esses dados, ele calcula o IMC e informa uma **classificação**:
   - Abaixo do peso
   - Peso normal
   - Sobrepeso
   - Obesidade
